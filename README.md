## Fake Product Detection using QR Codes and Random Forest

A QR Code-Based Framework for Fake Product Detection and Consumer Authentication using the Random Forest Algorithm.

---

##  Project Overview

Counterfeit products have become a serious issue affecting consumer safety, brand reputation, and the global economy. This project introduces a QR code-based authentication system integrated with the Random Forest machine learning algorithm to verify product authenticity in real time.

Each product is assigned a unique QR code containing product details. When the QR code is scanned, the system validates the product information using a trained Random Forest model and determines whether the product is genuine or counterfeit.

---

##  Objectives

- Detect counterfeit products using Machine Learning.
- Generate unique QR codes for every product.
- Authenticate products through QR code scanning.
- Improve consumer trust in product authenticity.
- Provide a low-cost and scalable authentication system.

##  System Workflow

1. Generate a unique QR code for each product.
2. Store product details in the database.
3. Consumer scans the QR code.
4. QR code is decoded.
5. Product details are verified.
6. Random Forest model predicts whether the product is Genuine or Counterfeit.
7. Authentication result is displayed to the user.
